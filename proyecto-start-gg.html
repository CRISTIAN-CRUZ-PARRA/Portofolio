Overlay para torneos de Rocket League

Ver en GitHub Ver Demo

Descripción

Si quieres sacar todos los datos posibles de algun torneo de start.gg con este programa sacas todos los datos que necesitas para ver quien puede estar haciendo trampas

Características

  • Tournament
  • ParticipantId
  • GamerTag
  • Prefix
  • Verified
  • ConnectedAccounts
  • PlayerId
  • PlayerGamerTag
  • Seed
  • Team
  • UserId
  • UserName
  • Country
  • City
  • discord_username
  • xbox_username

Tecnologías utilizadas
